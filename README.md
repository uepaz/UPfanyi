<h1 align="center">UP翻译</h1>

<p align="center">适用于 Windows 的 AI 翻译工具。阅读网页或文档时，选中文字并按下快捷键，就能在鼠标旁看到译文。</p>

## 功能特性

- 用**翻译小窗**对照阅读。点图钉可让小窗停在原文旁，译文完成后可一键复制。想改一个词时，展开「查看原文」编辑，再点翻译图标重译。
- 在**主窗口**输入或粘贴一段文字，按 `Enter` 就能逐段看到译文。开启「自动翻译」后，停下输入就会开始翻译。两个窗口同步目标语言，重启后仍沿用上次的选择。
- 在**官方 AI 和自己的服务**之间切换。每个渠道分别保存模型、密钥和系统提示词。
- 从**历史记录**找回译文，或点「继续翻译」接着修改。点击主窗口译文旁的星标，可将词句加入**收藏词本**，添加备注或导出为文本文件。

## 快速开始

### 安装

在 64 位 Windows 上双击 `UPfanyi_2.0.0_x64-setup.exe`，按向导完成安装。如果发布页只列出 1.x，可按下方步骤从 2.0 源码生成安装包。[查看已发布版本](https://github.com/uepaz/UPfanyi/releases)

<details>
<summary>从 2.0 源码生成 Windows 安装包</summary>

准备 Node.js 24、pnpm 11、Rust 1.94 或更高版本（MSVC 工具链）、Visual Studio 的「使用 C++ 的桌面开发」工作负载、Windows SDK 和 WebView2。在项目根目录运行以下命令。

```powershell
pnpm install --frozen-lockfile
pnpm desktop:build
```

安装包位于 `src-tauri/target/release/bundle/nsis/`。可运行 `pnpm verify` 检查代码并执行测试。

</details>

### 第一次翻译

1. 打开「设置 → AI 翻译」。首次启动已选中「UP翻译官方 AI」，在「API 密钥」中填入该渠道的密钥。[访问官方网站](https://uptoken.top)
2. 点击「获取模型」并选择一个可用模型，也可以直接填写模型名称。
3. 可先点「测试连接」确认配置，然后点「保存设置」。
4. 在网页或文档里选中一句话，按下并松开 `Ctrl+Shift+C`，即可在鼠标旁的小窗中阅读译文。

## 快捷键

| 默认按键       | 作用                                           |
| -------------- | ---------------------------------------------- |
| `Ctrl+Shift+C` | 翻译当前选中的文字                             |
| `Ctrl+Shift+T` | 显示主窗口                                     |
| `Enter`        | 翻译主窗口原文框中的文字                       |
| `Shift+Enter`  | 在主窗口原文框中换行                           |
| `Esc`          | 收起翻译小窗。如果语言列表已展开，会先收起列表 |

要更改两个全局快捷键，打开「设置 → 桌面与快捷键」，点击相应的快捷键输入框，按下新的组合键，再点「保存设置」。

## 常见问题

### 怎么使用自己的 AI 服务？

在「设置 → AI 翻译」的渠道列表中选择「添加渠道」并命名。服务地址只需填写域名，例如 `relay.example.com`。按服务支持的 OpenAI 兼容接口选择 `Chat Completions` 或 `Responses`，按需填写密钥，选好模型后保存。如果服务没有提供模型列表，可以直接填写服务商给出的模型 ID，再点「测试连接」。

### 关闭主窗口后还能划词翻译吗？

默认关闭主窗口会将应用收起到系统托盘，选区翻译快捷键仍然可用。要退出应用，可以在托盘菜单中选择「退出」。

### 翻译内容和密钥存在哪里？

翻译时，原文会发送给当前选用的 AI 服务。历史记录、收藏和设置保存在本机，具体位置可在「设置」底部的「本地数据目录」查看。API 密钥以明文保存在数据库中，请妥善保管数据库及其备份。
